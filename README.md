# SQL Practice Exam (คง UI เดิม)

ใช้ไฟล์ HTML/CSS เดิมเป็นฐาน พร้อมคลัง 55 หมวด 275 ข้อจากไฟล์ที่แนบมา

- สุ่ม 5 หมวด (25 ข้อย่อย) ต่อรอบ
- ตรวจคำตอบรายข้อ ดูเฉลยและคำอธิบาย
- ตรงเฉลยอ้างอิงให้ 4 คะแนน; คำตอบทางเลือกเป็นรอตรวจทาน และให้ผู้เรียนประเมินเองได้
- ไม่มีการประมวลผล SQL จริง และไม่ยืนยันว่าคำตอบที่ต่างจากเฉลยผิด
- บันทึกรอบสอบ/คำตอบ/ผลตรวจด้วย localStorage และเก็บประวัติ 50 รอบล่าสุด
- ส่งออกคำตอบเป็น TXT; เริ่มรอบใหม่ได้

เปิด index.html หรือใช้ Live Server; Bootstrap และ Google Fonts ต้องใช้อินเทอร์เน็ต

ไฟล์: index.html, style.css, questions.js, grading.js, app.js, README.md
