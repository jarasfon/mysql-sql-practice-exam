# SQL Practice Exam — Holistic Rubric

คง UI เดิม สุ่ม 5 กลุ่ม × 5 ข้อ = 25 ข้อ (100 คะแนน)

## การให้คะแนนรายข้อ
- 4 คะแนน: ตรงเฉลยหลัง tokenize SQL
- 3 คะแนน: โครงสร้างเกือบตรงและไม่มีความต่างของค่าคงที่/ตัวดำเนินการ
- 2 คะแนน: โครงสร้างใกล้เคียงแต่มีข้อผิดพลาดสำคัญบางส่วน
- 1 คะแนน: มีแนวทาง SQL ที่เกี่ยวข้อง แต่ยังไม่ตอบโจทย์
- 0 คะแนน: ไม่ตอบ หรือโครงสร้างไม่เพียงพอ

**คำเตือน:** คะแนน 0–3 เป็นการประเมินเบื้องต้นจากความคล้ายคลึงและโครงสร้าง ไม่ใช่การยืนยันว่า SQL ทำงานถูกต้อง เพราะระบบไม่ได้เชื่อมต่อ MySQL หรือรัน SQL จริง ข้อที่ใช้คำสั่งต่างกันแต่ให้ผลลัพธ์เดียวกันอาจถูกประเมินต่ำ ต้องตรวจทานโดยผู้เรียนหรือผู้สอน
