# MySQL & SQL Practice Exam

เว็บฝึกทำข้อสอบจำลอง MySQL สำหรับเตรียมสอบตำแหน่งนักวิชาการคอมพิวเตอร์ปฏิบัติการ

## ไฟล์ในโปรเจกต์
- `index.html` หน้าเว็บหลัก ใช้ Bootstrap 5 ผ่าน CDN
- `style.css` รูปแบบและการจัดหน้า
- `questions.js` ข้อสอบ 5 หมวด รวม 25 ข้อ พร้อมแนวคำตอบ
- `app.js` ระบบกรอกคำตอบ บันทึกอัตโนมัติ เปิด/ซ่อนเฉลย และส่งออกคำตอบ

## วิธีเปิดใช้งาน
1. ดาวน์โหลดหรือ Clone Repository
2. เปิด `index.html` ผ่านเว็บเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน VS Code
3. ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด Bootstrap และ Google Fonts จาก CDN

## การบันทึกคำตอบ
คำตอบถูกบันทึกใน `localStorage` ของเบราว์เซอร์และอุปกรณ์ที่ใช้งาน ไม่ได้ส่งขึ้น GitHub หรือเซิร์ฟเวอร์
หากล้างข้อมูลเว็บไซต์/เปลี่ยนเบราว์เซอร์ คำตอบอาจไม่อยู่ จึงควรกดส่งออกคำตอบเพื่อสำรองเป็นระยะ

## เผยแพร่ด้วย GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้ง 4 ไฟล์ไว้ที่ root ของ Repository
3. ไปที่ Settings > Pages
4. ใน Build and deployment เลือก Deploy from a branch
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด Save
6. รอ GitHub Pages สร้างเว็บไซต์ จากนั้นเปิด URL ที่ GitHub แสดงในหน้า Pages

## หมายเหตุ
- เป็นข้อสอบจำลองเพื่อการฝึกฝน ไม่ใช่ข้อสอบจริงจากหน่วยงานราชการ
- ระบบยังไม่ตรวจคำตอบ SQL อัตโนมัติ ผู้ใช้ต้องเทียบกับเฉลย
- ตัวอย่าง SQL อ้างอิง MySQL 8.0+
